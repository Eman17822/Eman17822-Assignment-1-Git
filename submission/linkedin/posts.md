Git Merge vs Rebase
الـ Merge بستخدمه عشان أدمج Branch مع Branch تاني مع الحفاظ على الـ history.
أما الـ Rebase فبيساعدني أخلي الـ history مرتب وخطي.

Git Squash
بستخدمه عشان أدمج أكتر من Commit في Commit واحد، خصوصًا لما أكون عملت كذا Commit صغير أثناء الشغل.

Git Cherry-Pick
بستخدمه لما أحتاج Commit معين من Branch تاني من غير ما أنقل باقي الـ Commits.
