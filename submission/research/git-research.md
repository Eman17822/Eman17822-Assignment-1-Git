 1. Git Squash

بستخدمه عشان أدمج أكتر من Commit في Commit واحد، وده بيخلي الـ Git history مرتب وأسهل في القراءة.

 2. Git Merge

بستخدمه عشان أدمج Branch مع Branch تاني، مع الاحتفاظ بالـ Commits والـ history زي ما هو.

 3. Git Rebase

بستخدمه عشان أجيب آخر تغييرات من Branch تاني وأخلي الـ history مرتب وخطي.

Merge vs Rebase:
Merge بيحافظ على الـ history زي ما هو، أما Rebase بيعيد ترتيب الـ history بشكل خطي.

 4. Git Help

بستخدمه لما أكون مش عارفة طريقة استخدام أمر معين أو الخيارات الموجودة فيه.

 5. Git Cherry-Pick

بستخدمه عشان أنقل Commit معين من Branch لBranch تاني، من غير ما أنقل باقي الـ Commits.

 6. Git Clean

بستخدمه عشان أحذف الملفات اللي موجودة في المشروع لكن Git مش متابعها.

 7. Git Grep

بستخدمه عشان أبحث عن كلمة أو جزء من Code داخل ملفات المشروع بسرعة.

 8. Git Blame

بستخدمه عشان أعرف مين عمل تعديل على سطر معين، وكمان الـ Commit اللي اتعمل فيه التعديل.

 9. Git Bisect

بستخدمه لما يظهر Bug ومش عارفة أي Commit هو اللي تسبب فيه، وبيساعدني أوصل للـ Commit ده.

 10. Git Shortlog

بستخدمه عشان أشوف ملخص للـ Commits ومساهمات الأشخاص في المشروع.

 11. Git Prune

بستخدمه لتنظيف الـ Repository من الـ Git objects اللي مبقاش ليها استخدام.

 12. Git Worktree

بستخدمه عشان أشتغل على أكتر من Branch في نفس الوقت، وكل Branch يكون في Folder منفصل.

 13. Git Verify-Commit

بستخدمه عشان أتأكد إن الـ Commit عليه Signature صحيحة.

 14. Git Filter-Repo

بستخدمه لو محتاجة أعدل في الـ Git history، زي إزالة ملف معين من الـ history كله.
